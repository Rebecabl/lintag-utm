Esse projeto é um **encurtador de links com UTM** (full-stack) que permite criar URLs curtas, **anexar parâmetros de campanha automaticamente** e **acompanhar cliques por dia** para gerar gráficos e relatórios. Ele é dividido em dois módulos: **API** (Node.js/Express + Firebase Admin/Firestore) e **Frontend** (React/Vite + Tailwind). Na prática, você cria um link curto com slug opcional; quando alguém acessa esse link, a API redireciona para a URL de destino (podendo **acrescentar utm_source/utm_medium/utm_campaign/utm_term/utm_content**) e registra o clique. As estatísticas podem ser consultadas via endpoint (`/links/:slug/stats`) e exibidas no painel web. O projeto já vem com **CORS, Helmet e rate-limit**, além de QR Code por link e configuração pronta para **deploy na Vercel**.
